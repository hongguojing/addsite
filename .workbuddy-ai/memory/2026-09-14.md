# 2026-09-14 工作日志

## QQ 分享适配（Open Graph 标签）

为 Astro 项目 `H:\addsite` 添加完整的社交分享元标签，使文章在 QQ/微信/Twitter 分享时显示标题、摘要、封面图卡片。

### 改动文件
1. **`src/layouts/BaseLayout.astro`** — 扩展 Props 接口（新增 `image`、`articleType`、`publishedTime`），在 `<head>` 中添加完整 OG 标签集（og:title/description/image/url/type/site_name/locale、article:published_time、itemprop 结构化数据、Twitter Card 标签、canonical 链接）。默认 OG 图 fallback 到 `public/images/og-default.png`。
2. **`src/pages/posts/[slug].astro`** — 向 BaseLayout 传递 `post.data.cover?.src`、`articleType="article"`、`post.data.date.toISOString()`。
3. **`public/images/og-default.png`** — 用 Python/Pillow 生成的 1200×630 默认分享图。

### 技术要点
- `import.meta.env.BASE_URL` 在此项目中为 `/addsite`（无尾斜杠），构造 URL 时需手动加 `/`
- Astro 内容集合的 `image()` schema 解析后 `cover.src` 已包含 base 路径（如 `/addsite/_astro/xxx.png`）
- 绝对 URL = `Astro.site` + 图片相对路径
- canonical URL 使用 `Astro.url.href`
