## 修复浅色主题（data-theme="light"）文字看不清
问题根因：
1. `src/styles/global.css` 的 `[data-theme="light"]` 块没有覆盖 `:root` 中的组件级变量（`--card-title` / `--card-excerpt` / `--card-date` / `--card-fallback-*` / `--hero-subtitle` / `--section-label` / `--link-*` / `--breadcrumb-*` / `--more-link-*`），这些变量保持深色主题的近白色值。
2. `.astro` 里大量写死 Tailwind 颜色（`text-[#eef4ff]` 等）与内联 style 标签配色，浅色主题无法通过 CSS 覆盖（PostCard.astro、posts/[slug].astro 最严重）。

做法：
- global.css：补齐浅色主题全部组件变量（深色可读值）、新增 `--card-hover-border` / `--focus-ring`；新增主题感知的 `.tag-pill` + `.tag-pal-0~5`（浅色用饱和深色文字）；补上 brand-icon、prose h1/strong/li::marker/blockquote 装饰、搜索面板/输入/按钮/结果卡、related-meta 等浅色覆盖；浅色卡片白底透明度整体上调（0.4~0.7 → 0.76~0.95）以压住背景图。
- .astro：写死颜色改为 `text-[var(--card-title)]` 等变量写法；标签配色从 JS 内联 style 换成 `.tag-pal-N` class。
- `.reading-meta-pill.tag-pill` 双 class 规则让文章页标签也能吃到配色变量。

验证：`node node_modules/astro/astro.js build` 通过；`astro preview --port 4321` → http://localhost:4321/addsite/

经验：对同一文件的多次 Edit 必须串行，并行编辑同一文件会互相覆盖（本次丢失过一次改动）。

## 顶栏（搜索栏）阅读时自动收起
问题：`.top-toolbar` 是 `position: sticky`，向下滚文章时一直悬在顶部挡视线。
做法：
- global.css：`.top-toolbar` 加 `transition: transform/opacity`；新增 `.top-toolbar.is-hidden`（`translateY(calc(-100% - 1.5rem))` + `opacity:0` + `pointer-events:none`）；`body.toolbar-hidden .reading-sidecar { top: 1rem }`（原 6rem）让目录栏跟着上移。
- BaseLayout.astro：新增滚动监听脚本——向下滚 >140px 收起，向上滚出现，搜索框聚焦时强制显示；`DELTA=6` 抖动阈值 + `requestAnimationFrame` 节流；`prefers-reduced-motion` 下由全局规则去掉过渡。

## 修复代码块（Shiki）深底深字
问题：Markdown 代码块由 Astro 默认 Shiki（github-dark）渲染，`<pre class="astro-code github-dark" style="background-color:#24292e;color:#e1e4e8">` 是**内联样式**；而浅色主题的 `[data-theme="light"] .article-prose code { color:#1f5c54 }` 作用到 `pre > code`，把文字变成深青 → 深底深字看不见。
做法：
- `astro.config.mjs` 加 `markdown.shikiConfig = { themes: { light: "github-light", dark: "github-dark" }, defaultColor: false }`，输出改为 `class="astro-code astro-code-themes github-light github-dark"` + `--shiki-light/--shiki-dark/--shiki-light-bg/--shiki-dark-bg` CSS 变量，不再有写死颜色。
- global.css：新增代码块双主题块——默认吃 `--shiki-dark*`（站点默认深色），`[data-theme="light"]` 下吃 `--shiki-light*`；并加 `.article-prose pre.astro-code code { color: inherit; background: transparent }`（(0,2,2) 特异性压过浅色主题的 `code` 规则）；浅色 `.article-prose pre` 只保留 border-color，不再设背景与文字色。
- 以后新增任何"内联样式写死颜色"的第三方输出（Shiki/图表等），都要用同样的变量+`[data-theme]` 方案，纯 CSS 覆盖打不过内联。
